# Матричный анализ отказоустойчивости компьютерных сетей

Данный репозиторий содержит программное решение и математическое обоснование задачи по проектированию отказоустойчивой локальной сети небольшого офиса. 

## 📌 Постановка задачи
Дана сеть из 6 устройств (Сервер, Wi-Fi-роутер, коммутатор и 3 рабочие станции) и 8 существующих каналов связи. Бюджет ограничен: разрешено проложить только **один дополнительный кабель**. Необходимо математически доказать, куда его проложить, чтобы сеть стала максимально устойчивой к отказам.

## 🛠 Используемые технологии и методы
*   **Язык:** Python 3.12
*   **Библиотеки:** `NetworkX` (анализ графов), `NumPy` (матричные вычисления), `SciPy` (спектральный анализ), `Matplotlib` (визуализация).
*   **Математический аппарат:**
    *   Матрица смежности и степени вершин.
    *   Поиск критических элементов (точек сочленения и мостов).
    *   Минимальный разрез (Min Cut) для оценки хрупкости связи между зонами.
    *   **Спектральный анализ:** Вычисление матрицы Лапласа (\(L = D - A\)) и числа Фидлера (\(\lambda_2\)) для выбора оптимального кабеля.

## 📊 Ключевые результаты

![График зависимости lambda_2 от варианта кабеля](https://github.com/user-attachments/assets/e3070146-d675-40f2-8d8d-3e6e8230c8bb)


1. **Устойчивость к одиночным отказам:** В исходной сети отсутствуют точки сочленения и мосты. Отказ любого одного устройства или канала не приводит к потере связности.
2. **Реальная уязвимость:** Минимальный разрез между серверной (узлы 1, 2, 3) и общим залом (узлы 4, 5, 6) равен **2**. Для нарушения связи требуется одновременный обрыв двух каналов (2-4 и 3-5).
3. **Оптимальное решение:** Перебор 7 вариантов дополнительного кабеля показал, что **кабель {1, 6}** является лучшим.
    * Он повышает минимальный разрез с 2 до 3.
    * Он максимизирует число Фидлера (\(\lambda_2\)) с 1.0 до 2.0, что обеспечивает максимальную спектральную связность.
